PowerShell UI — state and layout¶

The optional NativeHTMLKit.UI module provides state, computed values, layout and controls using only public NativeHTMLKit SDK cmdlets. The 0.1.0 UI build is a GitHub prerelease: verify Gallery availability and install from the appropriate release package if necessary.

Import-Module NativeHTMLKit.UI -ErrorAction Stop
$app = Start-NativeHTMLKitScript -Name 'Counter'
$ui = New-NHKUi -Title 'Counter' -Theme cobalt -Density compact
$count = New-NHKUiState -Value 0
$null = Add-NHKUiColumn -UI $ui -Content {
  $null = Add-NHKUiText -UI $ui -Bind $count
  $null = Add-NHKUiButton -UI $ui -Text 'Add 1' -Data $count -OnClick {
    param($eventObject,$state) $state.Set([int]$state.Value+1)
  }
}
try {
  $null = Start-NHKUi -UI $ui -Application $app
  Wait-NativeHTMLKit -Application $app -UntilShutdown
} finally {
  Stop-NHKUi -UI $ui
  Close-NativeHTMLKit -Application $app
}

Use the complete PowerShell UI demo for all simple components, and use PowerShell SDK reference for file dialogs and advanced native actions.
